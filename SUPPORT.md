## 🐛 Good issue reports

Use the repository's **bug or feature forms** for a focused, reproducible question.

Include:
- Your operating system and Python version (`python --version`)
- The exact command you ran
- Sanitized output or error text (no personal data)

**Do not include:**

- API keys, credentials, cookies, tokens, or account details
- Personal data or private investigation material
- Sensitive exploit details

For a potential vulnerability, use [SECURITY.md](SECURITY.md) instead of a
public issue.

## 💡 Suggesting something new

Have an idea for a new OSINT tool, workspace, command, or integration?

Open a **[Tool / Feature Suggestion](.github/ISSUE_TEMPLATE/tool_suggestion.yml)**
issue. Community suggestions shape what gets built next — see [ROADMAP.md](ROADMAP.md)
for the tracked list.

## 📐 Scope

OsaintMaint can help with:

- Its own local dashboard, data handling, and documented public-source connector behavior
- Tool Manager workflow, favorites, and catalog sync
- Export, quality, watchdog, audit, and site workspace behavior

Questions about a **third-party project listed in the Tool Manager** should usually
go to that project's own maintainers.
